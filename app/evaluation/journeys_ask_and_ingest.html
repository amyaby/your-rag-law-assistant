Critical details

Rephrase rulellm.py:157

If query has Arabic script → return unchanged. Else use Gemini to get formal Arabic search keywords, cached in-memory.

Memorymain.py:206-208, llm.py:347

Load last 12 messages from DB if conversation_id exists; inject last 6 into prompt as <turn role=...>. User turn saved before assistant? No: load before generation, then add_message(user) then add_message(assistant) at end. History bug: slice [-memory_turns:] = 6, not 12.

Retrievalretriever.py:25, hybrid.py

Single entry point uses hybrid by default. Dense 40 + BM25 40 → RRF with w_dense=1.0, w_bm25=0.35, k=60. Admission OR: similarity >= 0.78 or bm25 >= 0.6*best_bm25. Sort by (rrf_score, boosted_score).

CRAGretriever.py:41, corrective.py

Fires if best_dense < 0.78 (uses dense, not RRF). Chain adala→ism→web; each chunk scored by relevance, threshold crag_min_relevance. Empty allowed → caller reports no source.

LLMllm.py:106

Nested retry: for each model, up to llm_max_attempts with exponential backoff; 400/404/403 treated fatal → switch model; retryable 429/5xx/timeouts. History rendered to prompt, not chats API.

Persistencevector_store.py:207, main.py:250-255

If new conversation_id, create_conversation with truncated title; add_message(user), add_message(assistant). Title updated on first user message to first 48 chars.

Critical details

Health gatechunker.py:259

Reject if <20k chars, <15 chunks, avg>2500, or <50% chunks have article. Prevents garbage blobs.

Article-awarechunker.py:19,153

Regex ^المادة|مادة|الفصل|فصل + number/ordinals; French only if no Arabic. One article = unit; long articles windowed character-wise (4000/200).

Repairchunker.py:40-48

Fix split numbers across newlines (only when newline between halves) — avoids corrupting correct "447-1".

Embeddingembed.py:21,34

passage: for docs, query: for questions. Same model, L2 normalized, 384-d. Truncation at 512 tokens; 121/5844 chunks >~512 tokens.
